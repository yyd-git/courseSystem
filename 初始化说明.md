
## 🧩 适用场景
适用于课程选课系统 (`course_db`)，
包括课程（course）、学生（student）、选课（enrollment）三张表。

---

## ⚙️ 初始化方式

### 方式一：使用 Spring Boot 自动加载
确保你的 `application.yml` 配置如下：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/course_db?useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: 00000712
    driver-class-name: com.mysql.cj.jdbc.Driver
  sql:
    init:
      mode: always         # 启用脚本初始化
      schema-locations: classpath:db/schema.sql
      data-locations: classpath:db/data.sql
  jpa:
    hibernate:
      ddl-auto: none       # 不再自动建表，由 schema.sql 决定
    show-sql: true
